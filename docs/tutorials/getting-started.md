# دليل البدء السريع وإعداد بيئة العمل

هذا الدليل (Tutorial) سيأخذك في خطوات واضحة وبسيطة لإعداد بيئة العمل الخاصة بمشروع **QA Automation ERP GL** وتشغيل أول اختبار لك للتأكد من أن كل شيء يعمل بشكل سليم.

## المتطلبات الأساسية (Prerequisites)

قبل البدء، تأكد من وجود البرامج التالية مثبتة على جهازك:
1. **Node.js**: الإصدار 18.x أو أحدث. يمكنك تحميله من [الموقع الرسمي](https://nodejs.org/).
2. **محرر الأكواد IDE**: نوصي بشدة باستخدام [Visual Studio Code](https://code.visualstudio.com/).
3. **إضافة Playwright لـ VSCode**: قم بتثبيت إضافة `Playwright Test for VSCode` للحصول على تجربة تطوير أفضل.

## الخطوة 1: استنساخ المشروع وتثبيت الاعتمادات

1. افتح سطر الأوامر (Terminal) وانتقل إلى المجلد الذي ترغب في وضع المشروع فيه.
2. (في حال لم يكن المشروع لديك بالفعل) قم باستنساخ المستودع باستخدام Git.
3. انتقل إلى مجلد المشروع:
   ```bash
   cd QA-Automation-ERP-GL
   ```
4. قم بتثبيت الاعتمادات والحزم الخاصة بـ Node.js:
   ```bash
   npm install
   ```

## الخطوة 2: تثبيت متصفحات Playwright

لضمان توافق الاختبارات مع محرك Playwright، تحتاج إلى تثبيت المتصفحات الخاصة به (Chromium, Firefox, WebKit) والتبعيات الخاصة بنظام التشغيل:

```bash
npx playwright install --with-deps
```

## الخطوة 3: تشغيل اختبارات النظام الأساسية

الآن وقد أصبحت بيئة العمل جاهزة، دعونا نتأكد من أن إطار العمل (Framework) يعمل بشكل صحيح عن طريق تشغيل اختباراته الداخلية:

```bash
npx playwright test --project=framework
```
*ملاحظة: هذا الأمر يقوم بتشغيل الاختبارات الداخلية للمكونات الأساسية للإطار وليس اختبارات تطبيق ERP، للتأكد من أن المحرك الأساسي يعمل.*

## الخطوة 4: تشغيل اختبارات تطبيق ERP باستخدام واجهة المستخدم (UI Mode)

أفضل طريقة لاستكشاف وتشغيل الاختبارات أثناء التطوير هي وضع واجهة المستخدم (UI Mode). 
قم بتشغيل الأمر التالي:

```bash
npx playwright test --ui
```

ستفتح نافذة تفاعلية من Playwright:
1. من خلال النافذة، قم بتوسيع المجلد `apps/erp`.
2. ابحث عن أي ملف اختبار يحمل الامتداد `.spec.ts`.
3. انقر على زر "Run" بجانب اسم الاختبار.
4. شاهد الاختبار وهو يتم تنفيذه خطوة بخطوة!
